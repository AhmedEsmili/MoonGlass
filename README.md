# MoonGlass
4×1 liquid-glass moon phase widget (5 phases, current one centred & highlighted).

## Termux
    unzip MoonGlass.zip && cd MoonGlass
    bash termux_push.sh MoonGlass

This installs git+gh, logs in, creates the GitHub repo, pushes, waits for the
Actions build and downloads `app-debug.apk` into your Downloads folder.
Install it, then long-press home screen → Widgets → MoonGlass.
